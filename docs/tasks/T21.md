## T21: CI
Goal: every push and pull request runs the repo's done-checks, so a lesson with a wrong answer or a broken build
can't reach main (plan Phase 2: "validation script in CI"). Read CLAUDE.md first.
Files: .github/workflows/ci.yml (new)
Rules:
- On push to main and on pull requests: pnpm (version from package.json's packageManager or pnpm-workspace settings),
  Node from .nvmrc or 20 LTS, `pnpm install --frozen-lockfile`, then `pnpm typecheck`, `pnpm test`,
  `pnpm validate-content`, `pnpm --filter web build`.
- No secrets needed: the build must succeed without Supabase env vars (check that it does; if a page needs them at
  build time, report it rather than adding secrets).
- Cache the pnpm store.
Done when:
- the workflow passes on a branch push (the user approves pushing the branch), and a deliberately wrong lesson
  solution on a throwaway branch makes it fail
