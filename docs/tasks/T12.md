## T12: Missing functions + Excel compatibility fixes
Goal: the curriculum's Lookup and Text Search lessons can be written, and three known gaps match Excel.
Read docs/SPEC.md §3 and the curriculum table in Product spec §6 first.
Files: packages/engine/src/functions.ts, packages/engine/test/evaluator.test.ts, packages/engine/test/functions.test.ts (new)
Rules:
- XLOOKUP(lookup, lookup_array, return_array, [if_not_found], [match_mode], [search_mode]):
  match_mode 0 exact (default), -1 exact or next smaller, 1 exact or next larger, 2 wildcard (* ? ~);
  search_mode 1 first-to-last (default), -1 last-to-first (binary modes 2/-2 may fall back to linear);
  text matching is case-insensitive; no match → if_not_found if given, else #N/A; lookup_array and return_array of
  different lengths → #VALUE!. return_array may be a multi-column row/column range: until T6 spills, return the
  first value of the matched row/column (note it in a comment for T6).
- TEXTBEFORE(text, delimiter, [instance_num], [match_mode], [match_end], [if_not_found]) and TEXTAFTER(...same):
  instance_num negative counts from the end; match_mode 1 is case-insensitive; match_end 1 treats the end of text as
  a delimiter; delimiter not found → if_not_found, else #N/A; instance_num 0 or beyond length → #VALUE! / #N/A as Excel.
- VLOOKUP/HLOOKUP with an empty table or no match → #N/A (today VLOOKUP over an empty table gives 0).
- COUNTIF family: a criteria argument that is a reference to an empty cell is treated as 0 (Microsoft: "If the
  criteria argument is a reference to an empty cell, the COUNTIFS function treats the empty cell as a 0 value"), so
  COUNTIF(B2:B6, Y1) with Y1 empty counts zeros, not blanks. An omitted criterion COUNTIF(r,) behaves the same.
  A literal "" criterion still matches blank cells.
- A criterion string naming an error ("#N/A", "#DIV/0!", …) matches cells holding that error, also with "=" / "<>".
- Pure TypeScript, no DOM or Node APIs; write tests first; don't change the frozen Sheet/CellValue interface.
Done when:
- each rule above has tests with Excel's results (at least 40 new tests), including XLOOKUP not-found, wildcard and
  reverse search; TEXTBEFORE/TEXTAFTER negative instance, case-insensitive and match_end
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; no other files changed
