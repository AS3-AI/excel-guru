## T17: Shortcut steps
Goal: chord and sequence shortcut steps are playable, as in Product spec §3 "Shortcut steps". Runs after T15 and T16.
Files: scripts/validate-content.ts, scripts/validate-content.test.ts, scripts/fixtures/**,
       apps/web/app/(app)/lesson/[id]/steps/ShortcutStep.tsx (new), apps/web/app/(app)/lesson/[id]/steps/shortcut.css (new),
       apps/web/app/(app)/lesson/[id]/Player.tsx, apps/web/lib/platform.ts (new), apps/web/lib/platform.test.ts (new)
Rules:
- No formula bar. Listen for keydown on a focused practice area; normaliseKeys → gradeShortcutStep (chord) or collect
  presses → gradeSequenceStep (sequence). preventDefault() on any combo the lesson uses; never on browser-reserved ones.
- Show key-chip hints ("Hold ⌘ + Shift, press ↓"); pick the Mac variant automatically (platform.ts detects the OS from
  navigator.userAgentData / platform, with tests).
- Sequence steps advance one picture frame (pics[]) per correct key; a wrong key resets the sequence and counts as a
  wrong attempt.
- Touch devices: "Mobile device detected — Skip section" banner that skips the remaining shortcut steps of the lesson.
  Mac with keys.mac null: a skip bar for that step.
- Optional postcondition.selection / postcondition.grid shown after success on the mini grid.
- Attempts are recorded like other steps (input = the pressed combo or the joined sequence).
- Before grading or adding to a sequence, ignore key repeats (e.repeat), IME composition (e.isComposing, key
  "Process"), "Unidentified" keys and lone modifier presses in chord mode, so a held or stray key doesn't fail a step.
- Also fix scripts/validate-content.ts (allowed for this card): reject shifted US symbols (!@#$%^&*()_+{}|:"<>?~) as a
  shortcut's key and suggest the unshifted key with Shift (":" → "Shift+;"), because normaliseKeys can never produce
  them; add a fixture and test in scripts/.
Done when:
- a test lesson with a chord and a sequence step (kept under apps/web test fixtures, not content/, so order.json is
  untouched) plays on Mac and Windows key maps (unit tests on the pure parts,
  browser check for the rest), the mobile banner and Mac skip bar appear when they should
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; `pnpm --filter web build` succeeds; no other files changed
