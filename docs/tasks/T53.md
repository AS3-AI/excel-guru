- Fixed today: `new Sheet(grid, { today })` — an optional ISO date (default: the real date). TODAY() and NOW()

  ("2026-01-15"), so every learner and validate-content see the same answer. Lesson prompts say
  "In this lesson, today is 15 Jan 2026".
- Date display: a cell whose formula's result comes from DATE, DATEVALUE, TODAY, EDATE, EOMONTH, WORKDAY, or
  date ± number arithmetic (a date-typed operand plus/minus a number) is a date cell. Add `Sheet.isDate(addr)`
  (new, additive; existing Sheet methods unchanged). The grid shows date cells as `15 Mar 2024` (day, short
  month, year); values stay serial numbers for grading and for formulas that use them. Grid literals stay as
  typed (text like "2024-03-15" displays as text and works in date functions, as today).
- DATEDIF: start after end → #NUM!; unit "MD" stays as the engine computes it (lessons avoid "MD").
  Units Y, M, D, YM, YD tested against Excel examples.
- Lesson schema unchanged: date answers are serial numbers in expectedValue; validate-content keeps working.
