## T52: Statistical functions follow Excel
Goal: bugs found 16 Nov while preparing the Statistical module (range 4,"x",blank,10,7,7,2.5).
Files: packages/engine/src/functions.ts, packages/engine/test/functions.test.ts
Rules:
- MEDIAN, SMALL, LARGE, MODE, MODE.SNGL, MODE.MULT ignore text, blanks and booleans inside ranges (typed
  arguments count as Excel does: a typed number counts, typed text that isn't a number → #VALUE!).
  MEDIAN(A1:G1) → 7; SMALL(A1:G1,2) → 4; LARGE(A1:G1,2) → 7.
- SMALL/LARGE: k < 1 or k > count of numbers → #NUM!; k is truncated.
- MODE = MODE.SNGL: the most frequent number; ties → the one that appears first; no repeated value → #N/A.
  MODE.MULT: every most-frequent number, spilling down in first-appearance order.
- MEDIAN of an even count = average of the middle two; no numbers → #NUM!.
