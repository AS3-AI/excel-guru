## T24: Points, streaks and today's leaderboards
Goal: learners see their points and streak and today's top learners (Product spec §2.5, §3 right column, §7, §13;
System design §5). Data is already written by T19/T22.
Files: apps/web/app/api/leaderboard/route.ts (new), apps/web/app/api/share-bonus/route.ts (new),
       apps/web/lib/leaderboard.ts (new), apps/web/lib/leaderboard.test.ts (new),
       apps/web/components/Leaderboards.tsx (new), apps/web/components/ShareBonus.tsx (new),
       apps/web/app/(app)/lesson/[id]/Player.tsx, apps/web/app/(app)/lesson/[id]/player.css,
       apps/web/app/(app)/dashboard/page.tsx, apps/web/app/(app)/dashboard/dashboard.css, apps/web/components/TopNav.tsx
Interface (frozen, SPEC §5):
  GET /api/leaderboard?type=points|streak (public) → top 3 for today (IST)
  POST /api/share-bonus (user, once ever) → {points} (+500)
Rules:
- Leaderboards read the leaderboard_points_today / leaderboard_streaks_today views server-side with the admin client
  (they're revoked from anon/authenticated). Show username, first name, value, and the LinkedIn link when the
  profile has one; never emails or user ids. Ties share a rank.
- Right column of the player and the dashboard row: Today's High Scores (top 3 + "you: N points today"), Today's
  High Streaks (top 3 + your streak). Signed out: top 3 + "Log in to appear on the leaderboard" (§2.1).
- Streak copy, three states (§2.5): "Complete a lesson today to start your streak!", "Complete a lesson today to
  reach N days!", "Complete a lesson tomorrow to increase your streak!".
- Celebration: show "+N pts" (count-up) and the streak from POST /api/progress (already returned). "My points today"
  updates without a reload after a completion.
- Share bonus (§13): a card on the dashboard and lesson pages — "Share on LinkedIn for +500 points"; opens the
  LinkedIn share URL for the site, then POST /api/share-bonus grants +500 once (points_log reason "share-bonus",
  profiles.shared_on_linkedin = true); the card disappears after. Second call → 409, no points.
- Pure ranking/copy logic in lib/leaderboard.ts with tests first. Colours from tokens.css; no alert(); 375 px.
Done when:
- tests cover ranking ties, empty boards, the three streak copy states, share-bonus once-only
- locally against Supabase: a completion shows on today's board and in "my points today"; share bonus grants once
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; `pnpm --filter web build` succeeds; no other files changed
