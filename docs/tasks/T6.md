## T6: Dynamic arrays (spilling)
Goal: UNIQUE, FILTER and SORT (and a bare range like =A1:A3) spill down/right as in Excel 365, with #SPILL! when
blocked, so the Array formulas lessons can be written. Read docs/SPEC.md §3 first. Runs after T12.
Files: packages/engine/src/sheet.ts, packages/engine/src/evaluator.ts, packages/engine/src/functions.ts,
       packages/engine/test/sheet.test.ts, packages/engine/test/spill.test.ts (new), packages/engine/test/evaluator.test.ts,
       apps/web/components/grid/Grid.tsx, apps/web/components/grid/grid.css
Interface: the Sheet API stays frozen (constructor, set, get, getFormula, functionsUsed). get() of a spilled cell returns
  its spilled value; getFormula() of a spilled cell returns null (only the anchor holds the formula).
Rules:
- A formula whose result is a 2-D array writes it into the anchor cell and the cells right/below it.
  A 1×1 array is just a value. Implicit intersection (@) is out of scope.
- If any target cell (other than the anchor) holds a literal or a formula, or another spill, the anchor shows #SPILL!
  and nothing spills; clearing the blocker re-spills on recalc.
- Spilled cells take part in recalc: formulas that read them (e.g. =SUM(C2:C4) over a spill) update when the source
  changes, and a spill that shrinks clears its old cells. Cycles through spills → #CIRC!.
- Typing into a spilled cell makes it a normal cell and blocks the spill (#SPILL! at the anchor).
- UNIQUE(array, [by_col], [exactly_once]), FILTER(array, include, [if_empty]) (no match → if_empty or #CALC!-like:
  use #VALUE! since #CALC! isn't in ErrorCode), SORT(array, [sort_index], [sort_order], [by_col]); text compares
  case-insensitively, mixed types sort numbers < text < booleans, errors propagate.
- XLOOKUP with a multi-column return_array now spills the matched row/column (see T12's note).
- The spill-range operator (A2#) is out of scope (needs a tokenizer change).
- Grid: spilled cells show their values (from get()); give them a subtle visual cue from tokens.css; the formula bar
  shows the anchor's formula greyed for a spilled cell (getFormula is null). Grid size grows to include a spill.
- Engine stays pure TypeScript; tests first.
Done when:
- every rule above has tests (at least 40 new), including #SPILL! from a blocked cell, re-spill after clearing,
  shrinking spills, and a formula reading a spill
- every ExcelError, now including #SPILL!, has a test that produces it
- on /sandbox, =UNIQUE(A1:A5) over a list with repeats spills and typing into a spill cell shows #SPILL!
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; `pnpm --filter web build` succeeds; no other files changed
