## T18: Grid point mode and coloured references
Goal: the grid feels like Excel while typing a formula (decision 22). Read Product spec §4 first.
Files: apps/web/components/grid/Grid.tsx, apps/web/components/grid/FormulaBar.tsx, apps/web/components/grid/grid.css,
       apps/web/components/grid/Grid.test.ts, apps/web/components/grid/refs.ts (new), apps/web/components/grid/refs.test.ts (new)
Rules:
- Point mode: while editing a formula, right after "(", ",", an operator or "=", clicking or dragging a cell/range, or
  arrow keys (Shift+arrow to extend), inserts the reference at the caret; further arrows/clicks replace the last
  inserted reference. Typing anything else leaves point mode. Outside point mode arrows move the text caret as today.
- Coloured references: each reference in the formula being edited gets its own colour (a fixed palette defined in
  tokens.css via new tokens is not allowed — derive from existing tokens with color-mix), coloured in the editor text
  and outlined in the same colour on the grid. Use the engine's tokenize() to find references (never a regex).
- Space right after a column letter or row number typed in point mode inserts a whole-column ("B:B") or whole-row ("3:3")
  reference.
- The editor stays visible while pointing. Keep every T9/T11 behaviour (Tab out at the edges, commit-on-blur rules,
  unchanged-draft close, window-blur keep-open, reset on grid change, column widths, spill display from T6).
- Pure helpers in refs.ts (find references with positions, replace last reference, point-mode trigger rules) with
  tests first.
Done when:
- on /sandbox: typing =SUM( then clicking A1 and Shift+clicking A3 gives =SUM(A1:A3); arrows after "," insert and then
  replace a reference; each reference is coloured and outlined; Enter still commits
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; `pnpm --filter web build` succeeds; no other files changed
