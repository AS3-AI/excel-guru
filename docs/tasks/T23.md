## T23: Rich text in lessons + module membership fix
Goal: lesson text can bold key terms and show formulas as code chips (Product spec §3 "question card (rich text:
bold terms, inline code chips…)"), and lessons in multi-word modules (e.g. text-search) appear in their module.
Files: apps/web/components/RichText.tsx (new), apps/web/components/RichText.test.ts (new),

Rules:
- RichText renders a string with exactly two markups: **bold** → <strong>, `code` → <code class="chip">. Everything

  backticks win inside bold. Pure parser function exported and tested first.
- Use it for info text, every step prompt (formula, select, mcq legend, picture/project label, shortcut) and the
  explain text. mcq options and Show Answer solutions stay plain (they are formulas; show the solution as a chip).
- Chip style from tokens.css (monospace, subtle background, no wrapping inside a chip).
- modules.ts: a lesson belongs to a module when lesson.module equals the module's slug (not its title). Tests for
  "text-search" and "sum".
- Keep every T10/T11/T16/T17/T19/T20 player behaviour (focus, Enter, drawer, Show Answer, keys, saving).
