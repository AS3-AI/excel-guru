## T27: Lesson video and practice workbook download
Goal: the ▶ video button opens a modal when a lesson has a video; each lesson offers a downloadable .xlsx of its
first grid (plan Phase 3, Product spec §3).
Files: apps/web/app/(app)/lesson/[id]/Player.tsx (video button only), apps/web/components/VideoModal.tsx,
       apps/web/app/api/lessons/[id]/workbook/route.ts, apps/web/lib/workbook.ts(+test), apps/web/package.json, pnpm-lock.yaml
Rules: video is a YouTube embed (lesson.video holds the id) in an accessible modal (focus trap, Escape closes);
no video → button hidden. The workbook is generated server-side from the lesson grids (values and formulas), one
sheet per formula step, no answers included. Access rules match the lesson's.
Done when: tests for workbook generation; modal works by keyboard; checks pass.
