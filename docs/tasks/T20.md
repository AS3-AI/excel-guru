## T20: Dashboard, module pages, sign-up wall and lesson access
Goal: a learner sees their progress and the next lesson, and the free-tier rules start working (Product spec §1, §2.1,
§2.2, §2.4, §7). Runs after T19.
Files: apps/web/app/(app)/dashboard/page.tsx, apps/web/app/(app)/dashboard/dashboard.css,
       apps/web/app/(app)/modules/[slug]/page.tsx, apps/web/lib/modules.ts, apps/web/lib/modules.test.ts,
       apps/web/lib/access.ts, apps/web/lib/access.test.ts, apps/web/app/api/lessons/[id]/access/route.ts (all new),
       apps/web/app/(app)/lesson/[id]/page.tsx, apps/web/app/(app)/lesson/[id]/Player.tsx,
       apps/web/app/(auth)/signup/page.tsx, apps/web/app/(marketing)/page.tsx (CTA link only)
Rules:
- modules.ts: the 15 modules from Product spec §6 (slug, title, order); a lesson's module comes from its `module` field.
- /dashboard (public; signed out shows 0 / 85 and local progress): Total Lessons Completed card with the bar stacked by
  status (Low Accuracy, Needs Practice, Good) and "certificate when all lessons are done"; Next Recommended Lesson
  (first incomplete in order.json; after the last → /review); module cards with thin progress bars; Reset Progress link
  with a confirm modal (no alert()). Today's scores/streaks and projects are Phase 3/4: leave labelled placeholders.
- /modules/[slug]: breadcrumb, "x/N Lessons Completed", numbered list with incomplete lessons greyed.
- Sign-up wall: finishing Intro signed out redirects to /signup?completed=intro with copy about saving progress and
  unlocking more lessons; signing up merges eg_progress via T19's merge.
- Access (decision 18), decided on the server before the lesson renders and by GET /api/lessons/[id]/access
  → {allowed, reason: "ok" | "signup" | "paywall"}: Intro is free signed out; other lessons need an account; a free
  account gets 2 lessons in total (Intro counts); replaying a completed lesson is always allowed; a 3rd lesson without
  premium → redirect to /pricing (a placeholder page until Phase 3 is fine, but the redirect must be server-side).
  Premium = active subscription or membership of a group with has_paid_access (from Supabase).
- Landing CTA "Start free — no sign-up" opens /lesson/intro.
- Pure rules in access.ts and modules.ts with tests first. Colours from tokens.css; 375 px works.
Done when:
- access tests cover signed out, signed in free (0, 1, 2 lessons done, replay), premium and group premium
- locally: signed out → Intro → sign-up wall → sign up → progress merged → dashboard shows 1 done → a 2nd lesson opens →
  a 3rd redirects to /pricing (needs ≥ 3 lessons in content; use test fixtures if Lane C hasn't landed them)
