## T15: Grader for every step type
Goal: every non-info step type can be graded, so the player and the progress API can check select, shortcut, mcq,
picture and project steps. Read docs/SPEC.md §4 and Product spec §5 first.
Files: packages/grader/src/keys.ts (new), packages/grader/src/steps.ts (new), packages/grader/src/index.ts,
       packages/grader/test/keys.test.ts (new), packages/grader/test/steps.test.ts (new)
Interface (frozen, SPEC §4):
  export function normaliseKeys(e: KeyboardEvent): string;   // "Ctrl+Shift+ArrowDown"
  export function gradeShortcutStep(step: ShortcutStep, pressed: string, os: 'win' | 'mac'): boolean;
  export function gradeSequenceStep(step: ShortcutStep, pressed: string[], os: 'win' | 'mac'): boolean;
  export function gradeSelectStep(step: SelectStep, selection: string): boolean;   // "B2", "B2:C4", "B:B", "3:3"
  export function gradeMcqStep(step: McqStep, choice: number): boolean;
  export function gradeAcceptStep(step: PictureStep | ProjectStep, input: string): boolean;
Rules:
- normaliseKeys takes only the fields it needs (key, code, ctrlKey, altKey, shiftKey, metaKey) so it runs without a DOM;
  output uses the canonical form validate-content enforces: modifiers Ctrl, Alt, Shift, Cmd in that order, then the key
  (letters uppercase, named keys like ArrowDown, Enter, Tab, Escape, Space, F1–F24). Use `code` for letters/digits so
  Shift and Alt don't change the key (Alt+H on a Mac produces "˙" in `key`). A lone modifier press returns just it ("Alt").
- gradeShortcutStep: chord mode; compares `pressed` with keys.win or keys.mac by os; keys.mac null → false.
- gradeSequenceStep: sequence mode; the whole pressed list must equal the step's list (canonical form) for that os.
- gradeSelectStep: canonical form (uppercase, top-left first); "b2" and "B2:B2" count as "B2"; reversed corners count.
- gradeAcceptStep: normalise both sides (smart quotes → straight, remove all whitespace, lower-case), then match any.
- Pure TypeScript, no DOM or Node APIs (types from a minimal KeyboardEvent-like interface); tests first.
Done when:
- tests (at least 40) cover each function incl. Mac Alt-letter codes, Shift+digit, modifier order, null mac, reversed
  ranges, whole rows/columns, smart quotes and whitespace in accept answers
- `pnpm typecheck && pnpm test && pnpm validate-content` pass; no other files changed
